> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read the spec in full first. §n refers to spec sections.

**Goal:** Build Seatlock, a ticket-booking platform with a live seat map, expiring holds, a waiting room, signed payment webhooks and four benchmarked seat-locking strategies, end to end as the spec describes.

**Architecture:** An npm-workspace monorepo with `apps/api` (Express 5 + `pg` + ioredis), `apps/web` (React 19 + Vite + Tailwind 4) and `packages/shared` (zod contracts and geometry), plus `loadtest/` (k6). The build runs in three stages. First, one scaffold agent freezes the contracts and writes every cross-cutting module. Next, five parallel lanes each own disjoint files. Last comes integration, the benchmark run, review and the README.

## Review Focus
1. **Duplicate or foreign seat ids** in `POST /api/holds` (`[5,5]`, or an id from another event) must fail with `400 VALIDATION_FAILED`. They must not fail as a false `SEATS_UNAVAILABLE`, and they must not create a partial hold. Owner: B1 (`holds.routes.test.ts › rejects duplicate seat ids`, `› rejects seat ids from another event with unknownSeatIds`).
2. **A late webhook** (payment succeeds after `held_until`, while nobody else has taken the seats) must still sell the seats. Owner: B1 (`webhook.test.ts › sells seats when the webhook arrives after held_until but seats were not taken`).
3. **A double-clicked Pay** (two concurrent confirms with the same Idempotency-Key) must cause one payment attempt and one webhook. Owner: B1 (`mockpay.test.ts › concurrent confirms with one key make one attempt`).
4. **A skewed client clock.** The hold countdown and sale countdown must use the server time offset, not `Date.now()` alone. Owner: W1 (`serverClock.test.ts › remaining time is correct when the client clock is 5 minutes fast`).
5. **SSE gaps** (laptop sleep, a reconnect, a hidden tab) must trigger a snapshot re-fetch so the map never shows stale seats. Owner: W1 (`useEventStream.test.ts › refetches snapshot after reconnect`).
